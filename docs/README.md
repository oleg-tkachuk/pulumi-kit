# docs

What each document covers, and when it is the one to open.

| Document | Open it when |
|----------|--------------|
| [design.md](design.md) | you want to know why it is shaped this way: what each package owns, and which decisions are load-bearing |
| [ci.md](ci.md) | you are changing what lands, or working out why a check ran — or did not |
| [releases.md](releases.md) | you want to know how a version gets cut, and what a commit type releases |

The per-command references live beside the code, in
[cmd/target](../cmd/target) and [cmd/stack](../cmd/stack). The
[root README](../README.md) is the entry point.
